# কুরআন শরীফ

বাংলা ভাষাভাষী ব্যবহারকারীদের জন্য কুরআন অ্যাপ।

## Features

- সম্পূর্ণ ১১৪ সূরা
- Arabic Quran
- বাংলা অনুবাদ
- আয়াতে tap করলে শব্দার্থ popup
- Word-by-word meaning
- তাফসীর
- Quran audio
- নামাজের সময়
- Qibla direction
- Tasbih
- Hadith section
- Dua section
- Last read
- Dark mode
- Font size control
- Android WebView application
- GitHub Actions APK build

## Android Build

GitHub Actions workflow:

`.github/workflows/release.yml`

Manual build:

1. GitHub repository খুলুন
2. Actions এ যান
3. Build Quran Sharif APK নির্বাচন করুন
4. Run workflow চাপুন
